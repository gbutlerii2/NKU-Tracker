Tracking application for North Kitsap United.
North Kitsap United (NKU) is a collaborative initiative created to meet the growing need for quality sports fields and active 
recreation facilities in North Kitsap County — a region where youth and families currently face limited and overcrowded play 
spaces and little to no options for active recreational activities.

This application takes and tracks all donors, donations, events, work phases, work tasks, workers, documents, calendar, and agenda
for the entire project so budgets can be fully tracked and the $25M project can remain on task.

Current site is www.nku-tracker.com
